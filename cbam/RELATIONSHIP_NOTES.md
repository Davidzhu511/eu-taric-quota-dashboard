# CBAM 与 EU ETS：页面解释口径

- CBAM certificate 与 EUA 不是同一资产。EUA 是 EU ETS 下可交易的排放配额，存在一级拍卖和二级现货/衍生品市场；CBAM certificate 是进口商履约凭证，没有类似 EUA 的自由二级市场。
- CBAM 证书价格的法律锚来自 EU ETS 一级拍卖清算价。2026 年按进口季度的 EUA 拍卖成交量加权平均价定价；2027 年起改为周度成交量加权平均价。
- EUA 二级市场价格并不直接写入 CBAM 定价公式，但二级市场承担主要价格发现和套保功能。套利、做市和套保会使二级市场与一级拍卖价格难以长期脱节，因此期货/现货变化会间接传导到拍卖，再传导到 CBAM。
- EEX 每周 CBAM Reference Price 与欧委会官方价格使用同源的 EUA 拍卖数据，可用于跟踪和预测，但最终法律结算以欧委会公布价格为准。
- 大量进口商购买 CBAM certificate 本身不会机械触发欧盟同步买入等量 EUA，因此不存在“CBAM买证量直接推高下一场EUA拍卖价”的一对一机制；但企业若为未来 CBAM 负债使用 EUA 期货等工具套保，可能通过二级市场形成间接反馈。
- 影响 EUA / CBAM 的核心变量包括 ETS cap 与拍卖供应、MSR、能源价格与燃料切换、电力与工业排放、天气/可再生能源、政策预期、金融持仓和远期曲线。
