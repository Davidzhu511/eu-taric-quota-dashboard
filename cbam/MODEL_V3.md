# 2027 购证窗口

从 `cbam/data/current.json` 读取 `procurement_window`。每日刷新时间是 17:30 UTC，配套 Chat 任务建议在工作日 21:15（Europe/Berlin）运行。

| 字段 | 口径 |
| --- | --- |
| `as_of`、`mode` | 布鲁塞尔当地日期。2027-02-01 前只作模拟；2026 年模拟以普通周二换期回放，2027 年 1 月使用已公布的周价。 |
| `current`、`next` | 当前与紧接的下一窗口，各自记录证据类型、形成周及已知的公布/适用日期。官方价优先。估值只使用 EEX ETS1 成交量加权清算价。 |
| `spread`、`impact_per_1000` | 下一期减本期（欧元/张、欧元/千张）。正值表示本期较便宜。缺值为 null。 |
| `threshold`、`direction` | 门槛为 max(€2，当前价格×2%)。跨过门槛可独立提醒。 |
| `spread_points`、`history_points` | 前者为 30+30×价差/门槛，限于 0–60。后者为 40×(1−当前价百分位)，与形成周以前 26 个完整拍卖周比较，同价取中间名次。输入不足只保留可核实部分。 |
| `score`、`percentile` | 总分达到 65 或百分位进入最低 20% 时，复核可择时需求。权重与门槛为初始业务参数。 |
| `actionable` | 当前官方价、适用期、下一窗口和来源达到公开比较条件。实际办理仍需确认申报人账户、付款时间及平台规则。 |
| `official_cbam_prices`、`official_weekly_prices`（顶层） | 欧委会 2026 季度价与后续周价分开存档。记录保留原始适用年度。 |

完整周按 EEX 日历逐场核对。周内估值要求至少三场、成交量达到已公布计划量的三分之二，已到期的计划场次须能核实。无计划拍卖的周按第21(1)条参照最近的实际成交周。官方周价表需能识别列名与发布日期；欧委会尚未发布真实 2027 周价表。实际表头不兼容或已过有效期，页面显示缺项并记录异常。官方显式适用日期优先；依第21(2)条推算时，采用已核实年度的欧委会布鲁塞尔工作日。超出已核实年度时要求官方适用日期。

Chat 研究使用 `cbam/data/research.json`。有已核实的新公开结论时填写 `meta.status=research_note`、`updated_at`（带时区）、`confidence`、`public_data_date`、`headline`、`summary`、`bullets` 和 `sources`，`overlay_score` 保持 null。按窗口、方向和事实变化去重。客户合同、台账、持仓和申报数据留在私下。复盘时按相同义务与期限比较等额分批购证的实际成本、最差误判及按期足额情况。

## 工作日定时研判

1. 读取最新 main 的 `cbam/data/current.json`、`cbam/data/research.json`，比对最近一次已分析窗口。先看 `as_of`、`checked_at`、`data_date`、来源状态和当前有效期。工作流延迟时仅补核影响判断的官方来源。周末、节假日及正常无拍卖日沿用原始日期。
2. 2026 年进口仅跟踪季度固定价、法定张数、资金及首次交证。开售前只报重要模拟或合规事项。2027 年当年义务检查有效官方价、相邻窗口、支付及到账条件。已过可办理时间的价格仅作回顾，周五重点看下一工作日。时间按 Europe/Berlin。
3. 价差达到门槛独立提醒。65 分或半年最低 20% 首次触及、供给或远期市场重大变化时，复核是否值得调整已确认需求。检查影响证书数量、费用、办理期限的欧委会和 EUR-Lex 正式新规；明确草案及生效日。涉及第22(2)、(2a)条时须核实申报人适用季度和台账，尤其首次超过质量门槛的季度。没有台账时只提示需核对事项。
4. 通知先给业务动作和期限，再列义务年度、两个价格及证据、每1,000张影响和来源。已确认可灵活安排的张数才能用于测算金额。按年度、适用期、方向去重；确认值或方向、金额、期限有实质变化才再报。有新增可核实公开研究时按上述格式取最新文件 SHA 写回并回读；单次失败有限重试。连续两个应更新工作日发生同一故障提醒一次，影响临期则当轮提醒。其余静默，例行任务不重抓全量、不改代码或调度、不代为交易。
