    1. CBAM证书没有独立的自由二级市场

    EUA是EU ETS的可交易排放配额，可以在一级拍卖和二级现货/衍生品市场交易；CBAM certificate主要是进口商的行政履约凭证，不能像EUA一样自由转手交易。因此不存在一个独立的“CBAM市场情绪”直接形成碳证价格。

    2. CBAM价格直接锚定EUA一级拍卖

    CBAM定价公式读取EU ETS拍卖清算价，并按拍卖成交量加权。也就是说，法律上的直接链条是“EUA一级拍卖价 → CBAM证书价”。2026年采用季度均价；从2027年起改为周度均价，因此采购时点开始真正影响2027当年义务的购证成本。

    3. EUA二级市场虽然不直接进入公式，但会间接影响CBAM

    期货和现货市场承担价格发现、套保和套利功能。若二级市场价格明显高于或低于一级拍卖，参与者会调整投标和交易，因此两者很难长期脱节。EUA期货曲线、现货价格、金融持仓最终会通过拍卖价格间接传导至CBAM。

    4. 大量购买CBAM证书不会机械推高下一场EUA拍卖

    购买1张CBAM证书并不意味着欧盟必须同步在市场买入或注销1张EUA，因此不存在“CBAM抢购 → 自动产生等量EUA买盘”的一对一机制。但如果进口商或金融机构为了未来CBAM负债使用EUA期货等工具套保，可能先影响二级市场，再间接传导至一级拍卖和未来CBAM价格。

    5. EEX周度CBAM参考价的用途

    EEX周度CBAM Reference Price与欧委会官方价格使用同源的EUA拍卖数据，因此非常适合跟踪“本周价格正在往哪里形成”；但它本质上是参考指标，最终法律结算仍以欧委会正式公布的CBAM certificate price为准。

    6. 对公司采购最重要的结论

    2026进口义务的单价已经按季度锁定，2027付款早晚主要影响现金流；2027及以后当年进口义务才需要重点判断周度价格、远期曲线和供给趋势，以决定维持50%合规底仓还是提高到60% / 70% / 85% / 100%的高置信度覆盖水平。
